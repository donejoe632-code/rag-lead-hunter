Автоматизированная система поиска и квалификации B2B-клиентов для внедрения RAG-систем (Retrieval-Augmented Generation), корпоративных баз знаний и автоматизаций на Python.

---

## 🚀 Что делает инструмент
1. **Сбор лидов по триггерам:**
   - Мониторит **Telegram-каналы** с вакансиями и вытаскивает **прямые контакты рекрутеров, CTO и фаундеров (`@username`)**.
   - Сканирует **Хабр Карьеру** по болям саппорта, онбординга, документации (`Notion`, `Confluence`, `база знаний`).
   - Парсит **HeadHunter (HH.kz / HH.ru)** через headless-браузер Playwright.
2. **AI-анализ и квалификация:**
   - Определяет ведущую проблему бизнеса: *Перегрузка саппорта*, *Хаос в документах*, *Долгий онбординг новичков*, *Поиск по договорам*.
   - Выставляет балл приоритета от 1 до 10 (`rag_score`).
3. **Генерация персонализированных офферов:**
   - Для каждого лида генерирует индивидуальный текст для **Telegram**, **Email** и короткую записку для **LinkedIn**.
4. **Экспорт данных:**
   - 📊 `output/leads_rag_target.xlsx` — стилизованная Excel-таблица с кликабельными ссылками и сортировкой по приоритету.
   - 📋 `output/leads_rag_target.csv` — CSV в кодировке `utf-8-sig` (для Google Таблиц / Notion / CRM).
   - 📝 `output/hot_leads_digest.md` — дайджест ТОП-горячих лидов с готовыми текстами для отправки прямо сегодня.

## ⚡ Как запускать

### 1. Быстрый сбор (Telegram + Хабр Карьера) — рекомендуется для старта:
```bash
python main.py --mode quick
```

### 2. Полный сбор (Telegram + Хабр + HeadHunter через Playwright):
```bash
python main.py --mode all --area kz
```
Доступные регионы для HH: `--area kz` (Казахстан), `--area almaty`, `--area astana`, `--area cis`.

### 3. Только Telegram-каналы с прямыми @контактами:
```bash
python main.py --mode telegram
```

## 💡 Регламент B2B-аутрича (Как закрывать сделки)

1. **Не продавайте «RAG и Python»**: Бизнесу всё равно, на чём это написано. Продавайте «Сокращение времени ответа саппорта на 40%» и «Ускорение онбординга стажёров без отвлечения сеньоров».
2. **Пишите по 10–15 сообщений в день**: Берите готовый текст из `hot_leads_digest.md`, открывайте профиль контакта в Telegram и отправляйте.
3. **Цель первого контакта**: Не продать за 500 000 ₸ сразу в чате, а **вытащить на 15-минутный созвон-демонстрацию**.
4. **Демонстрация**: Загрузите их открытые регламенты / PDF в своего тестового бота прямо перед созвоном и покажите: *«Вот ваш документ — вот бот цитирует пункт 4.1 и не фантазирует»*. Конверсия такого демо в оплату — от 30% до 50%.
